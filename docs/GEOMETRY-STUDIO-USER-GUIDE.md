# 零部件模板生成器——几何页面使用说明

## 1. 几何页面的目标

几何页面用于建立零部件模板的权威参数化几何，不是只绘制一个固定尺寸的实例。完成后的草图应当具备：

- 可编辑的二维图元。
- 稳定的工程语义 ID。
- 明确的几何约束。
- 可绑定模板参数的尺寸。
- 明确的实体外环、孔洞和多腔区域。
- 在最小、标称、最大参数工况下保持稳定的几何和拓扑。

推荐的完成顺序是：绘制截面 → 设置建模模式与平面 → 建立约束和尺寸 → 定义截面区域 → 处理诊断 → 配置三维几何配方。

## 2. 通用二维参数化草图

### 2.1 作用

该区域是二维截面的直接编辑画布。当前权威基础图元为点、直线、圆和圆弧。矩形是一个快速绘制工具，会展开为四条可独立编辑的直线，不会生成不透明的复合图元。

### 2.2 操作方法

1. 选择“点”、“直线”、“矩形”、“圆”或“圆弧”工具。
2. 在画布中按图元要求依次点击：
   - 点：一次点击。
   - 直线：起点和终点。
   - 矩形：两个对角点。
   - 圆：圆心和圆上一点。
   - 圆弧：起点、圆弧经过点和终点。
3. 切换到“选择”工具。单击选中一个图元；按住 Shift 或 Ctrl 可多选。
4. 在“标称”工况下，可以拖动已选直线的端点，或拖动圆和圆弧的圆心。
5. 使用“撤销”和“重做”回溯草图编辑。
6. 切换最小、标称和最大工况，查看参数变化后的解算结果。最小和最大工况用于验证，不直接拖动修改。

坐标输入和拖动修改的是标称草图的几何初值，画布应立即显示编辑结果，随后再显示约束求解后的权威结果。如果求解后的形状与拖动方向不同，说明尺寸或几何约束正在驱动该图元，应修改对应驱动参数或调整约束，而不是反复拖动。

### 2.3 底部状态

- **几何通过/几何失败**：当前三种工况是否存在几何或拓扑错误。
- **剩余自由度**：尚未被约束或尺寸确定的变量数量。正式复核前应为 0。
- **有效截面区域**：当前工况下连续闭合的实体或孔洞区域数量。
- **主选图元**：当前在属性区编辑的图元。

## 3. 当前对象与草图设置

### 3.1 截面建模模式

建模模式定义求解器和 B-Rep 编译器如何解释闭合轮廓，不只是界面显示选项。

#### 单闭合区域

适用于一个主实体截面，例如实心平板、实心棒料截面和普通拉伸件。默认草图是一个可参数化的矩形外环。

#### 多环／多腔区域

适用于外环中包含孔洞、管材或多个独立截面区域的情况。默认草图包含一个加材外环和一个减材内环，便于理解管类或孔洞截面。

当前默认图形采用常用矩形管：外轮廓由截面宽度、截面高度驱动，内轮廓尺寸由 `sectionWidth - 2 * thickness` 和 `sectionHeight - 2 * thickness` 求值，形成等壁厚空腔。用户仍可修改图元、尺寸和区域，将其改为圆管、方管或多腔型材。上述截面和传统管材参数均由同一个“开口型材/管材拉伸”算子生成。

#### 中心线＋厚度薄壁

适用于 C 型、U 型、Ω 型、帽形等开放薄壁截面。草图只绘制板材中性层／中心线路径，`thickness` 参数定义实体厚度，几何配方使用“中心线＋厚度薄壁拉伸”。当前稳定算子支持连续直线段和折角；圆弧折弯半径仍需用实际闭合轮廓表达，后续再纳入圆弧偏置版本。

切换模式时平台会询问：

- **保留当前草图**：只更改区域解释模式，保留已绘制图元、约束和区域。适用于已经建模，准备手工调整区域的情况。
- **重建默认草图**：用新模式的可编辑示例草图替换现有草图。该操作可撤销，适合初始建模或希望从新默认结构开始的情况。

### 3.2 截面所在平面

“基准平面”就是二维截面草图在三维坐标系中所在的平面。

| 选项 | 草图坐标 | 平面法向 | 典型解释 |
| --- | --- | --- | --- |
| XY | X、Y | Z | 截面在水平面上，拉伸方向通常为 Z |
| XZ | X、Z | Y | 截面在竖直面上，拉伸方向通常为 Y |
| YZ | Y、Z | X | 截面在另一竖直面上，拉伸方向通常为 X |

切换平面不应改变草图的二维尺寸、图元数量、约束和区域拓扑；它改变的是这张草图在三维空间中的放置和后续几何算子的默认方向解释。

### 3.3 当前图元属性

在画布中选中一个图元后，可以设置：

- **稳定 ID**：图元在约束、区域和几何配方中的机器引用。可以修改，平台会同步更新当前草图中的约束和区域引用；发布后不应随意更名。
- **图元名称（工程语义）**：用户可自定义的业务含义，例如“左翼缘外边”“孔中心基准”。它用于阅读、检索和 AI 理解，不代替稳定 ID。
- 图元不再手工维护“驱动参数”。参数影响关系由尺寸约束和几何算子自动推导，避免出现只关联图元却没有真正驱动几何的无效关系。
- **构造图元**：仅用于定位、对称或尺寸基准，不参与截面区域和 B-Rep 实体生成。
- **坐标**：编辑标称工况的原始几何位置。建立完整约束后，应优先通过参数和尺寸改变形状，而不是直接改坐标。

### 3.4 轮廓图元与构造图元

- **轮廓图元**参与闭合环识别，可以成为实体外环或减材内环，最终参与 B-Rep 截面生成。
- **构造图元**只作为尺寸、对称、同心、定位和接口基准，不参与闭合区域，也不会生成实体边。坐标轴、中心线、孔距基准线通常应设为构造图元。

二者使用相同的点、线、圆、圆弧和约束能力，差别只在是否参与材料区域。把图元从轮廓改为构造后，应重新识别并复核截面区域。

## 4. 草图设计意图

### 4.1 图元

显示当前草图的所有基础图元和构造属性。单击图元卡片会与画布选择联动。删除图元时，平台会同时清理其无效约束和区域引用。

### 4.2 几何约束

1. 在画布中选中所需图元。
2. 在约束类型中选择重合、水平、垂直、平行、正交、相切、同心、对称、相等、固定、点在曲线上或闭环，再点击“新增几何约束”。单图元约束至少选择一个图元，关系约束至少选择两个图元。
3. 确认约束卡片中的图元标签正确。
4. 如需修改，重新选择图元后点击“用当前选择替换作用图元”。

不需要手工输入图元 ID。

约束选择规则如下：

| 约束 | 选择要求 | 含义 |
| --- | --- | --- |
| 水平 | 一条或多条直线 | 每条直线分别平行于草图 X 轴 |
| 竖直 | 一条或多条直线 | 每条直线分别平行于草图 Y 轴 |
| 平行 | 至少两条直线 | 后续直线相对第一条平行 |
| 正交 | 至少两条直线 | 后续直线相对第一条成 90° |
| 相切 | 恰好两个支持的曲线对象 | 直线与圆/圆弧，或两个圆/圆弧相切 |
| 同心 | 至少两个圆或圆弧 | 共用圆心 |
| 对称 | 两个对象＋一条构造直线 | 第三个图元是对称轴 |
| 点在曲线上 | 一个点＋一条曲线 | 必须先选点，再选曲线 |

界面会同时校验选择数量、图元类型和选择顺序；不符合契约时“新增约束”不可用，并显示正确的选择要求。

### 4.3 尺寸与参数

1. 在画布中选择直线、圆弧或圆。
2. 选择需要控制的几何量：线段长度、水平跨度 `ΔX`、垂直跨度 `ΔY`、半径、直径或相对 X 轴角度。
3. 点击“为当前选择建立尺寸”。
4. 设置尺寸的工程名称，例如“管材外宽”。
5. 选择驱动方式：固定值、驱动参数或参数表达式。
6. 切换最小、标称、最大工况，确认该尺寸在参数边界下都可求解。

若所需参数尚不存在，点击“定义新参数”，填写参数 ID、名称、单位、最小值、标称值、最大值、来源和作用域，再决定是否在零部件实例生成时开放。创建参数不会自动关联当前图元；必须回到尺寸卡片，将驱动方式设为“驱动参数”并选择该参数。

已有参数可在参数卡片中展开编辑名称、单位、来源、作用域以及最小／标称／最大值。参数与几何的权威关系为：

- 参数绑定尺寸后，平台从尺寸的作用图元自动推导“影响图元”。
- 参数也可以由三维几何算子直接引用，例如 `length` 驱动拉伸长度。
- 参数卡片中的驱动关系只读展示，不允许额外手工勾选图元。

只有来源为“实例输入”且作用域为“零部件实例”的参数，才允许勾选“实例生成时开放输入”。材料属性、公式、组件配置、产品配置和项目区域参数均由相应来源提供，在零部件实例页面只读或隐藏。

模板中应尽量将用户需要调整或上游需要引用的尺寸绑定为参数，把仅用于建模稳定的辅助值保留为内部尺寸。

### 4.4 截面区域

截面区域决定二维轮廓如何生成 B-Rep 截面：

- **生成实体**：该闭合环内部为有材料区域。
- **作为孔洞**：该闭合环从外环中减去。

可以点击“重新识别”从连续闭合轮廓生成区域。自动识别后仍要检查每个区域的加材/减材意义和边界顺序。

### 4.5 诊断

诊断页签统一显示：

- 欠约束和剩余自由度。
- 约束冲突和冗余约束。
- 未知图元或区域引用。
- 开放轮廓、零面积区域和自交。
- 最小、标称、最大工况之间的拓扑不稳定。

点击可定位的诊断项后，画布会选中相关图元。也可使用“AI 审查”生成待工程师确认的修改建议，AI 不会自动覆盖草图。

诊断页中的“边界工况验证矩阵”是三工况确认的依据：

1. 最小、标称、最大三行均显示“通过”。
2. 三行的剩余自由度均为 0。
3. 三行的闭合区域数量一致，且符合设计意图。
4. 驱动参数值分别落在参数定义的最小值、标称值和最大值。
5. 诊断列表中不存在约束冲突、开放区域、自交或拓扑签名变化。

顶部三个工况按钮的状态点提供快速结果，绿色表示该工况通过，红色表示失败；正式复核以诊断矩阵和诊断列表为准。

## 5. 开口截面和管状截面

### 5.1 开口薄壁截面

C 型、U 型、Ω 型等“开口截面”是指构件截面的空腔向外开放，不代表用于生成实体的材料轮廓可以开口。实体 B-Rep 仍要求一个闭合的有材料区域。

推荐建模方法：

1. 选择“单闭合区域”。
2. 沿板材实际外表面绘制轮廓，从一侧自由端依次经过翼缘、圆角、腹板等位置。
3. 沿内表面反向返回另一侧自由端。
4. 在两处自由端用表示板厚端面的短线连接，使材料边界形成一个闭环。
5. 对共线、相切、平行、对称和板厚建立约束；把宽度、高度、折边、圆角和厚度绑定参数。
6. 重新识别区域，应得到一个“生成实体”区域，而不是一个开放线链。

平台现已提供“中心线＋厚度薄壁”算子，可使用连续直线链生成开口薄壁实体。需要精确圆弧折弯、内外圆角或板厚偏置控制时，当前仍应使用实际闭合材料轮廓；中心线圆弧偏置进入稳定算子包后再切换。

### 5.2 管状截面

圆管、方管、矩形管和多腔型材使用“多环／多腔区域”：

1. 绘制外轮廓闭合环，并设为“生成实体”。
2. 绘制一个或多个内轮廓闭合环，并设为“作为孔洞”。
3. 圆管通常用两个同心圆，并分别绑定外径（或内径）与壁厚关系。
4. 方管或矩形管使用外矩形和内矩形；用水平、垂直、同心/对称、圆角与等厚关系约束。
5. 多腔型材应为每个空腔建立独立减材内环，所有内环必须完整位于加材外环内部且互不相交。
6. 在三工况验证矩阵中确认外环/内环数量、加减材关系和拓扑签名始终不变。

## 6. 完成与复核标准

草图达到以下条件时才可勾选“草图设计意图已复核”：

1. 最小、标称、最大工况均求解通过。
2. 剩余自由度为 0。
3. 没有约束冲突、开放环、自交或零面积区域。
4. 区域拓扑在三种工况下一致。
5. 实体外环和孔洞内环的工程意义正确。
6. 所有对外开放的关键尺寸均已绑定明确的参数来源。

完成草图后，在“几何配方”中选择拉伸、旋转、扫掠、放样、钣金或其他几何算子，将二维权威草图转换为三维零部件基体。
