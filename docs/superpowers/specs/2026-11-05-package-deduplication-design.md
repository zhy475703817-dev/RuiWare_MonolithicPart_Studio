# 模板包内容判重与发布确认

用户已确认：点击发布时检查；无候选直接发布；仅存在候选时提示，再打开比较弹窗，由用户选择新增包或替换旧版本。

## 内容规则

整包 SHA-256 相同为完全重复。实际定义按几何 55%、参数行为 25%、特征与接口 12%、制造与材料 8% 加权。总分 >=90%、几何 >=95%、参数 >=90% 才是高度相似；80% 以上未达到强候选门槛，或几何与参数达到门槛但其余差异明显，为疑似相似。低于 80% 且核心定义不接近时不提示。

从包内定义 JSON 提取语义；不比较发布身份、版本、时间、压缩顺序、产物路径与哈希、说明文档、证据、审核状态和显示名称。保留参数和几何内部 ID、引用、表达式、单位、范围、默认值及几何操作顺序。有 ID 的无序定义集合按 ID 对齐，操作列表保序。按类别中定义文件等权、文件内语义叶节点匹配率评分；关键结构或参数行为变化另行列出，不因文本相似而掩盖差异。缺失定义不能获得满分。

## 发布与清理

在冻结本地发布前检查远程包。候选报告包含四项分数、字段级旧值/新值及内容快照令牌。新增和替换必须携带有效令牌；再次发布会重新检查，候选变更时重新确认。替换只接受用户明确选择的完全重复/高度相似候选。

新包上传并下载校验成功后才删除旧包。删除前再次核对旧包 SHA、当前成员写入前缀、引用查询结果。引用未知、有引用或其他成员包均不可删除。引用服务必须原子建立持久删除预留，所有引用写入方必须拒绝预留/已删除版本的新引用；不支持预留、未配置服务或查询失败均禁用替换。删除后完成预留，清理失败保留预留，不自动超时解锁。详见 `docs/TEMPLATE-PACKAGE-DEDUPLICATION.md`。

MinIO 列表保留每个发布 ID。提供独立分组接口供组件平台接入：相同整包 SHA 合并展示并保留 publicationIds；高度/疑似相似只关联并提供比较结果。固定发布 ID 的详情和下载继续独立解析。

## 验证

覆盖包元信息变化、名称相同但定义不同、操作顺序、参数默认值和表达式、缺失定义、阈值边界、取消不发布、令牌失效、未知/已有引用、跨成员删除、上传失败保留旧包、发布 ID 可独立访问。前端类型检查、构建及现有测试。
