# 模板重建说明书设计

## 目标

在发布零件模板时，根据同一个冻结修订自动生成一份可人工阅读、可逐项核对、可定位错误的 Markdown 说明书，并将其写入 `.rwpart` 模板包。

## 设计

- 文档由后端从 `TemplateDraft` 生成，不接受用户手工上传作为权威内容。
- 文档与发布修订绑定，发布后的文档不能根据后续草稿变化。
- 文档覆盖模板信息、参数、材料、草图图元与约束、几何配方、制造特征规则、变体、接口、求解结果、阶段检查和复现步骤。
- 每个可排错对象保留稳定 ID 和数据路径，错误表直接引用阶段检查项 ID、路径和修复建议。
- `.rwpart` 继续保留现有 JSON 文件，新增 `template-reconstruction-guide.md`；`manifest.json` 记录文档文件名和 SHA-256。
- 发布页提供当前修订的说明书预览和 Markdown 下载入口；历史版本仍通过其不可变 `.rwpart` 下载。

## 发布流程

```text
冻结发布修订 -> 生成 Markdown -> 写入 .rwpart -> 记录发布版本
```

如果说明书生成失败，发布操作失败，不创建不完整的发布包。

## 非目标

- 第一版不生成 PDF。
- 不改变现有参数、规则、草图、CAD 和发布校验逻辑。
- 不把说明书作为独立业务数据保存，避免文档与模板模型发生漂移。
